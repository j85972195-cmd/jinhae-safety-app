# 부산 진해신항 컨테이너부두 1-1공구 스마트 안전관리 — 웹앱 프로토타입

## 구성
- 순수 HTML/CSS/JavaScript
- 외부 서버/DB 없이 동작
- 모바일 반응형
- PWA 설치 가능
- 위험신고 데이터는 현재 휴대폰 브라우저의 localStorage에 저장
- GitHub Pages에 그대로 배포 가능

## 중요
현재 지도·수치·연락처는 프로토타입용 예시입니다.
실제 운영 전 다음을 교체해야 합니다.
1. 실제 현장 배치도
2. 실제 안전관리자/비상연락처
3. 협력업체 목록
4. 사내 작업허가·점검·위험성평가 양식
5. 실제 DB/로그인/권한
6. 서버 저장 및 관리자 화면
